# 💖 Website Nembak Spesial Buat Hanan

Website interaktif romantis & lucu dengan gradasi warna pink-ungu yang manis untuk nembak cewek idaman.

---

## ✨ Fitur-Fitur Utama

1. **Tombol Interaktif yang Membesar Menutupi Layar**:
   - Jika tombol **"Tidak 🥺"** ditekan, tombol **"Diterima! 🥰"** akan membesar secara dinamis.
   - Kata-kata di tombol "Tidak" berganti secara lucu dan memohon (misal: *"Yakin gamau? 🥺"*, *"Jangan nolak plisss 😭💔"*, dll).
   - Setelah ditekan beberapa kali, tombol "Diterima" akan **mengambil alih seluruh layar (Full Screen)** dengan animasi denyut cinta, sehingga tidak ada pilihan lain selain menerimanya!

2. **Perayaan Kemenangan Romantis ("Selamat Telah Menjadi Pacar Hanan Yeyyy!")**:
   - Ketika tombol "Diterima / Iya" ditekan:
     - Ledakan **Confetti Partikel Hati** warna-warni (pink, ungu, emas).
     - Suara kemenangan romantis (Web Audio API bawaan browser, tanpa perlu file audio tambahan).
     - Tulisan besar: **"Selamat Anda Telah Menjadi Pacar Hanan! 💍✨"**
     - Kartu **Piagam Resmi Hubungan** dengan tanggal jadian otomatis.
     - Tombol **Kirim Bukti ke WhatsApp Hanan** yang sudah terisi pesan manis otomatis.
     - Tombol **Hujan Cinta Lagi** & Surat Janji Hanan yang bisa dibuka.

3. **Desain Sweet Pink & Purple Gradient**:
   - Latar belakang gradasi halus pink ke ungu dengan partikel cinta melayang.
   - Kartu kaca (*Glassmorphism*) yang elegan dan responsif di HP maupun Laptop.

---

## 🚀 Cara Menjalankan

Buka terminal di folder project ini:

```bash
npm run dev
```

Buka browser di [http://localhost:3000](http://localhost:3000).

---

## 🌐 Cara Deploy Online (Agar Bisa Dikirim Link-nya ke Doi)

Agar pacar kamu bisa buka lewat link di HP-nya sendiri:
1. Upload folder ini ke GitHub kamu.
2. Buka [Vercel](https://vercel.com) lalu klik **Import Project** dari GitHub kamu.
3. Klik **Deploy** (gratis).
4. Kamu akan mendapatkan link seperti `https://mylove-hanan.vercel.app` yang siap dikirim ke dia! 💌
